### 🟢 核心设计：引入“待确认状态机”

目前你的对话系统是：`用户说话 -> 大模型识别 -> 直接执行 -> TTS 播报结果`。
现在我们要改成两步走：**识别出危险操作后，立刻暂停，进入“待确认状态”，等待用户二次语音。**

**完整交互流程（演示剧本）**：
1. **用户**说：“把工单号 123 改为已完成”。
2. **大模型**解析出 `{"intent": "operate", "params": {"ticket_id": 123, "new_status": "已完成"}}`。
3. **系统不执行数据库修改**，而是立刻在内存中记录一个“待办事项”，并触发 TTS 播报：“**您确定要把工单 123 的状态改为已完成吗？请回答确认或取消。**”
4. **系统进入锁定状态**（不接收其他新指令）。
5. **用户**说：“确认”（或者“是”、“是的”）。
6. **系统**执行 SQL 修改，TTS 播报：“**修改已成功执行。**”
7. *（如果用户说“取消”或“否”，系统清空待办，TTS 播报：“**操作已取消，未做任何修改。**”并且超时 30 秒不回复，自动取消。）*

在 `backend/app.py` 中引入一个基于内存（字典）的对话状态管理。你可以直接在 `app.py` 的顶部加入以下代码：

```python
import time
from flask import request, jsonify

# 全局变量：使用字典保存“待确认操作”（key 可以用用户的 session_id 或者简单的 1 表示单用户）
# 实际工程中此状态应存入 Redis，开发环境直接用内存足以
user_sessions = {}

def execute_confirmation_logic(user_text, session_id="default"):
    now = time.time()
    session = user_sessions.get(session_id)

    # 1. 检查是否处于【等待确认】状态
    if session and session.get('state') == 'WAITING_CONFIRM':
        # 超时判断：超过 30 秒未确认，自动取消
        if now - session.get('timestamp', 0) > 30:
            user_sessions.pop(session_id, None)
            return {"reply": "等待确认超时，操作已自动取消。", "state": "CANCELLED"}

        # 2. 解析用户的确认/取消回答
        if user_text in ['确认', '是', '是的', '确定']:
            # 执行保存的待定操作
            op = session['pending_op']
            # 调用数据库更新方法
            if op['action'] == 'change_status':
                db_service.update_ticket_status(op['ticket_id'], op['new_status'])
            # 操作完成，清除会话
            user_sessions.pop(session_id, None)
            return {"reply": f"工单 {op['ticket_id']} 状态已成功修改为 {op['new_status']}。", "state": "EXECUTED"}
        
        elif user_text in ['取消', '否', '不要']:
            user_sessions.pop(session_id, None)
            return {"reply": "操作已取消，未修改任何数据。", "state": "CANCELLED"}
        
        else:
            # 用户说了别的乱七八糟的话，继续提示确认
            return {"reply": "我没听清，请问您确定要执行该操作吗？请回答‘确认’或‘取消’。", "state": "WAITING_CONFIRM"}

    # 3. 非等待确认状态（正常解析大模型）
    return None
```

#### 1. 新增 `search_tickets_dynamic` 函数（`backend/db_service.py`）
```python
def search_tickets_dynamic(params: dict) -> list:
    """
    多条件动态搜索工单
    params 结构示例：
    {
        "assignee": "张三",
        "status": "未完成",
        "priority": "高",
        "keyword": "数据库",
        "start_date": "2026-04-01",
        "end_date": "2026-04-08",
        "ticket_id": None
    }
    """
    conn = get_connection()
    cursor = conn.cursor()
    
    # 核心：使用 WHERE 1=1 动态拼接 SQL（防止 SQL 注入，使用参数化查询）
    sql = "SELECT * FROM tickets WHERE 1=1"
    sql_params = []
    
    if params.get('ticket_id'):
        sql += " AND id = ?"
        sql_params.append(params['ticket_id'])
        
    if params.get('assignee'):
        sql += " AND assignee = ?"
        sql_params.append(params['assignee'])
        
    if params.get('status'):
        sql += " AND status = ?"
        sql_params.append(params['status'])
        
    if params.get('priority'):
        sql += " AND priority = ?"
        sql_params.append(params['priority'])
        
    if params.get('keyword'):
        # 关键词模糊搜索（标题或描述）
        sql += " AND (title LIKE ? OR description LIKE ?)" # 假设你有description字段，没有就只查title
        like_keyword = f"%{params['keyword']}%"
        sql_params.append(like_keyword)
        sql_params.append(like_keyword)
        
    if params.get('start_date'):
        sql += " AND create_time >= ?"
        sql_params.append(params['start_date'])
        
    if params.get('end_date'):
        sql += " AND create_time <= ?"
        # 由于时间可能带时分秒，为了包含当天，加一天
        sql_params.append(params['end_date'] + " 23:59:59")
        
    cursor.execute(sql, sql_params)
    rows = cursor.fetchall()
    
    cursor.close()
    conn.close()
    
    # 转换成字典列表（和 get_tickets 格式保持一致）
    return [{"id": r[0], "title": r[1], "status": r[2], "priority": r[3],
             "create_time": r[4].isoformat(), "assignee": r[5]} for r in rows]
```

### 🔥 核心联动逻辑：如何让“点击未完成卡片”后，表格自动过滤？

上面的 `router.push` 已经包含了参数：`?filterStatus=未完成`。
**你需要同步修改你的 `TicketsPage.vue` 组件**，在页面加载时自动读取这个参数，并应用筛选。

在你的 `frontend/src/views/TicketsPage.vue` 中（布局里用下拉框筛选的地方），加入这段监听代码：

```javascript
import { watch } from 'vue'
import { useRoute } from 'vue-router'

const route = useRoute()
// 假设你的筛选变量叫 `filterStatus`（或者是你 store 里的状态）
const filterStatus = ref('全部') 

// 监听路由参数，一旦从首页跳转过来，自动改变筛选变量
watch(() => route.query.filterStatus, (newVal) => {
  if (newVal) {
    filterStatus.value = newVal // 下拉框会自动被赋值为"未完成"
    // 如果你表格数据是通过 computed 基于 filterStatus 动态过滤的，表格就会瞬间变化
    // 比如：filteredTickets = computed(() => ticketStore.tickets.filter(t => t.status === filterStatus.value))
  }
}, { immediate: true })
```
